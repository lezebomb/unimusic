# Phase 2Q：聚合搜索调度与本地分页

日期：2026-10-28。针对“一个来源慢，其他来源也要等”的搜索体验，改动调度/本地检索，不修改原唱、版本、时长或音频权限门槛；没有重启YouTube取流排查。

此前聚合入口在启动网络请求前主线程展平/筛本地库，本地索引任务也占4个共享槽之一；5个在线来源中排在后面的来源可能等待其他任务。现在本地库等待初始化、筛选、去重、索引和排序都在Default后台，五个现有在线来源使用5个有界在线槽，本地任务不占在线槽，六个来源各自仍受原6秒预算约束。最快来源可以先发结果，失败不触发串行整轮重启。未来新增在线来源仍受固定上限，不自动无限并发。

本地会话只构建一个索引，同查询分页复用完整排名并直接切30条视图，不重复扫描/重排整库或复制整段剩余列表。构建逐歌检查取消，过期查询不继续建立索引。库快照在该次本地任务初始化后固定，后续新搜索再接新库状态。
