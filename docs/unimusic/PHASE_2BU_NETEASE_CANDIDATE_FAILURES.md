# Phase 2BU — 保留网易云候选失败原因

2026-10-30（Asia/Shanghai）。接续 2BT 真机发现的 UNAVAILABLE 折叠问题。

网易云播放解析内部现在携带结构化失败原因，正常播放入口仍返回原有 SongUrlResult。来源检查、已记忆匹配和反向备用入口共享该结果：明确试听→PREVIEW_ONLY，无权限→NO_PERMISSION，超时→TIMEOUT，网络异常→NETWORK，登录失效→AUTH_REQUIRED。不再把这些失败统一伪装成 UNAVAILABLE，也不把权限/试听误作为传输失败进入自动冷却。原会话、决定、预算、取消与显式开关复核保留；具体候选检查不递归启动其他备用源。

设备诊断只作少量修正：无版本查询不再选中 live/edit，加入主源检查，最多每个平台两条合格候选；不播放、不确认来源、不改开关、不输出 URL/账号。
