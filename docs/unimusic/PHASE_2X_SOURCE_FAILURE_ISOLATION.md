日期：2026-10-28。PlaybackSourceResolver现在把仍有效调用内的适配器自身超时/取消/解析异常作为当前候选失败，继续下一候选；真正父请求取消仍传播且不误入失败冷却。明确socket超时为TIMEOUT。SourceAvailabilityChecker对应返回TIMED_OUT/UNAVAILABLE，避免单次校验内部超时取消整个搜索探测。

原生QQ/酷我并行备用链路复用racePlaybackSources，每个子任务都在finally用非挂起通知报告结束；即使来源自行取消，也不再等待缺失通知直到阶段预算耗尽。首个合格成功返回并取消其余任务，父取消仍停止全部子任务；任务保持结构化，不脱离原预算。主原生来源自身超时也可继续既有备用链路。

严格标题/歌手/版本/时长、权限/会话、人工决定复核和自动映射保存条件沿用，不新增来源或放宽匹配。此次只修复失败控制流，不能宣称所有来源实际播放通过。
