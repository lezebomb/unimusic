# Phase 3A：可撤销的本地推荐偏好

2026-10-28（Asia/Shanghai），接续 4A 双标签界面。

## 行为

- 本地推荐卡片可选“30天内不推荐这首歌”，立即过滤同一精确本地身份，可从提示撤销，也可用“恢复已隐藏”清除本机隐藏偏好。不移除歌曲、收藏、歌单成员或下载，不按同名合并不同录音。
- 偏好变动触发日内重选，旧日快照也在恢复时过滤当前候选；普通统计变化仍保持每日顺序。未设置偏好时跳过额外身份散列。
- 只持久保存 SHA-256 身份摘要与到期时间，最多1000条、文件最大128KiB，原子刷盘后再发布修订。不是账号凭据、播放日志或第三方上传接口。格式未知/损坏时不覆盖原文件，推荐降级并给出提示。
- 撤销令牌校验该次到期值，旧撤销不会覆盖后来的同曲选择。独立操作提示保留撤销，不被普通通知去重吞掉。

## 实际验证

- `LocalRecommendationFeedbackStoreTest` 3项通过：磁盘重开/精确身份/30天过期与恢复；并发选择/同毫秒新决策及旧撤销；写入失败与未知版本不覆盖原数据。没有运行完整历史套件。
- Debug APK、模块边界通过。处理连续操作提示及默认无偏好路径后仅重建 APK，没有重复运行不受影响的测试。实际 XML、哈希及命令见 [证据](evidence/2026-10-28/phase3a/validation.json)。
- Mate60 保留数据覆盖安装成功；验证隐藏、提示撤销、偏好落盘、强制结束后重开、恢复全部隐藏、完整推荐集合恢复；全程播放器保持暂停，测试偏好最终已恢复。没有保存真实歌名、身份摘要或账号数据，见 [设备检查](evidence/2026-10-28/phase3a/device-feedback.json)。首次设备断言错误假设撤销会重置横向滚动，实际列表保留锚点；已改为核对偏好与推荐集合，不因此修改正确的滚动行为。
