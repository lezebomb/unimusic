# Phase 2S：候选排序计算与搜索键隔离

日期：2026-10-28。排序优先级和自动匹配门槛不变，减少昂贵元数据评估的重复调用，并防止结构化搜索结果键碰撞。

`RecordingDiscoveryRanker`按每个去重候选预计算匹配、规范化标题/歌手和时长差，比较器只读这些字段。保留版本预筛、原有录音证据优先级和同分稳定顺序；未知上下文仍可留给详情检查，多个合格上传仍需人工选择。

歌曲搜索键对种类/平台/资源/分P/URI/旧ID的每个位置做长度前缀编码。字段中的竖线或缺失字段不再造成不同结果同键；改显示歌名不会改变源身份键。不修改Room身份、队列或持久来源决策，v3自动证据继续沿用。
