# Phase 3D.5：远端UUID到本地播放适配

日期：2026-10-28。远端UUID可经已持久的精确别名找到本机已有歌曲；不改原UUID、来源、歌单或用户元数据。

- 缓存身份/别名索引，同文件的日志实例共享修订，只有修订变化才重读文件。只读查找返回明确的未知/本机缺失/删除/冲突状态；不依赖标题猜测，不重建私有路径。
- 现有本地ID仍优先走原Room路径；只有原ID无法加载时才查别名，最多检查32个本地候选。远端删除或冲突不猜测候选；不自动删本机歌曲，完整跨设备删除应用仍需后续显式处理。
- 远端引用成功后沿用本机原有持久元数据、精确来源键与用户来源决策，不复制临时音频URL或授予权限。返回的内部source-match ID仍为原本机Room ID，避免外键/决策错绑。
- 外来UUID携带日志修订；临播解析完成及缓存更新前复核，过期结果不应用。已有直接本地路径无需读取身份日志；解析总预算仍沿用原实现，没有增加新的网络取流。
