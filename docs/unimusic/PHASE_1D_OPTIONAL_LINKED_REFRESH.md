# Phase 1D：已关联歌单的可选定期刷新

2026-10-28（Asia/Shanghai）。接续 4A 与 3A，完善网易云导入后台。

## 行为与数据保护

- “我的→导入歌单→导入任务”新增“每天刷新已关联歌单”，默认关闭，独立本机 DataStore 保存，不进入设置同步或备份。开启后约每24小时、联网且电量非低时安排现有导入流程，第一次也延迟24小时。
- 只刷新 `netease + LINKED + linked + COMPLETED`；已取消、认证暂停、失败和部分失败需要手动操作，一次性导入不会自动关联。事务内再次检查完成状态和关联，避免快照读完后覆盖新的用户操作。
- 周期任务只安排正常导入 Worker，不另写网络导入器或下载音频。现有分页/账号变化检查、顺序/UUID、幂等、保留本地删除与重命名、空远端不删除等语义复用原实现。排队/等待重试的关联任务仅用 KEEP 补建丢失的 WorkManager 请求，不清空失败退避或替换正在运行的手动任务。
- 每次安排前复核开关与当前会话；退出/换号停止后续安排。关闭取消周期计划，已经开始的普通导入仍可在任务页取消；解除关联继续保留本地内容。
- 启动后在可交互界面出现后校准唯一周期任务。采用 UPDATE 保留原入队时间，避免每次启动推迟执行；该语义已核对 [Android 官方 API](https://developer.android.com/reference/androidx/work/ExistingPeriodicWorkPolicy#UPDATE)。不保证固定钟点，系统可延迟后台工作。

- 2项调度资格策略检查和1项 Room/Fake 导入检查通过，包含排队保护、自动补充新增、保留用户重命名/删除、取消及解除关联。没有重复运行完整导入套件。
- 主APK、AndroidTest APK和模块边界通过。Mate60保留数据覆盖安装两包成功，单个真机测试验证反复启用仅一个活动周期任务、关闭后取消、偏好恢复；实际输出 `OK (1 test)`。
- 实际导入页确认开关可见、现有会话下可用、最终关闭。未开始新导入或打印账号，原始测试XML、设备输出、哈希及命令见 [validation.json](evidence/2026-10-28/phase1d/validation.json)。
