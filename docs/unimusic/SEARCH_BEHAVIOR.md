# 当前搜索规则与验收边界

截至2026-10-30，源码实现以2AY～2BQ及最新检查点为准。这里描述UniMusic实际使用的规则；未取得网易云内部检索或推荐模型的源码。

| 环节 | 当前行为 |
| --- | --- |
| 初始召回 | 本地、网易云、B站、酷我独立返回及翻页；QQ/YT已停用，历史数据保留。网易云原始页顺序保留为意图判断输入。 |
| 歌手/作品意图 | 每查询最多一次歌手索引请求，与歌曲首页并行，预算1200ms；歌曲证据返回后再发布意图。唯一精确名/别名，或最多3实体与原始前6条中至少4个独立合法网易云资源且不少于2/3署名一致（重复资源/外源/坏ID不作独立证据）。明确歌名/版本歧义保持原歌曲意图。 |
| 关联结果 | 歌手卡片和平台实体ID署名歌曲优先；其他Catalog需与本查询最多64条网易云录音核对规范标题、完整署名、时长和版本。当前跨Catalog时长容差为4秒。 |
| 版本证据 | 同层优先符合请求的录音版；识别翻唱、现场、伴奏、混音、串烧、变速、重制、重录、合成人声，以及Bootleg/Rework/受制作人合作标签限定的Booty。Live版/Cover版/Mash Up版等中英形式不漏判。 |
| 地址状态 | 网易云/酷我各最多3候选、各总预算4500ms、单次最多1800ms，取得完整地址即停。地址状态在同录音/版本约束内提升排序；点击播放优先并取消推测检查。 |
| 自动备用 | 网易云已记住来源/本地匹配后，新酷我与B站备用并行；首个完整且通过既有录音/权限门槛的结果胜出，取消落选任务，发布前复核账号/网络/开关。统一解析8秒截止时间不变，不是首声承诺。 |
| 列表位置 | 用户未滑动时跟随真正顶部，后台key移动不当成用户滚动；用户真实滑动后保留锚点，新查询上下文重置。 |

以上时间是代码中的上限，不能当作首屏、首声或真实切源耗时。歌手索引是后台补充，现有元数据先显示；接口失败会保留已返回结果。来源独立失败/重试，不删除其他健康结果。没有真实延迟或原唱准确率百分比。

跨源核对是元数据门槛：A/B与AB保留不同署名边界，未知别名/版本不自动提升。仅同名歌手或有效地址不能证明同一录音；未确认候选仍在列表后面，可由用户明确选择。原唱认证不能由这些规则完整替代音频指纹、发行与权利资料。

播放器持续显示平台明确返回的试听状态。没有试听证据的普通短歌曲不会仅因时长被标记；地址校验、实际解码、试听片段和完整版验收分别记录。当前所选乐队歌曲的20/30秒设备样本仍是试听，不承诺全部歌曲免费或完整可播。

已复查的例子：哭泣少女乐队在最终包上显示两关联乐队及雑踏、僕らの街/Cycle Of Sorrow，后台校验后仍在顶部；Adele稳定结果有Easy On Me/Hello等。没有为这些歌手硬编码名字或ID。实际设备、关键XML、APK哈希与中间失败见[2BA报告](PHASE_2BA_RECORDING_EVIDENCE_AND_SEARCH_ANCHOR.md)和[检查点](RESUME_CHECKPOINT.md)。

2026-10-30累计2BC包已在Mate60复核原乐队查询与原曲顶部顺序，随后20秒试听实际进度增长，完整歌曲/切源速度仍未验收；远端40918996595整体成功。初次设备计数脚本的分隔符误判已更正，失败的“Adele”拼音未提交输入不计入查询验收。

2BJ补充：精确中英文未知歌手占位词不构成署名证据，不自动跨源匹配或建立歌手卡片/推荐亲和度。完整真实名称含Unknown等字样时仍正常识别；已知歌曲身份上的实际反馈不变。

2BK补充：歌手精确名/别名保留署名分隔边界及顺序，不把AC/DC、ACDC和DC/AC自行等同；明确平台别名仍有效，无精确名的显式多段查询保持歧义，不用作品共识强推单歌手。

2BL补充：日文歌ってみた/弾き語り/カバー、繁体翻彈/彈唱和Off Vocal/カラオケ等明确标签纳入版本证据；仅专辑说明含标签也要核对，不凭可用地址提升为原录音。

2BQ补充：歌手索引为2分钟/8查询/4项的内存缓存，歌曲页仍10秒；账号/来源开关上下文失效一起清除，失败不缓存。重复查询可复用索引，推断仍核对当前歌曲证据；未提供新增真机耗时或准确率数字。
