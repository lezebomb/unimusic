# Phase 2T：健康翻页与失败重试分离

日期：2026-10-28。解决聚合页中失败来源反复参与“加载更多”、拖住健康结果的后台与入口行为。

健康来源独立保留游标并翻页，失败来源留在顶部状态条由显式重试处理。重试只请求失败来源，不推进健康游标或重取已完成平台；已有结果、去重和全查询取消保持。超时/网络错误有不同固定文案，局部错误不会将整个分页按钮变成重试循环。

服务端游标变化却没有新增身份时标为该来源不可用，停止自动翻页并保留旧结果，用户仍可显式重试。来源内部更短的timeout/取消在整轮仍有效时落到终止状态，避免永久loading；真正父查询取消仍传播，不回填过期结果。
