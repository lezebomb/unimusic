# Phase 2M：真实账号导入与音源真机验证

日期：2026-10-27。基线为 `64c7d699`；Room 保持 v23，没有新增迁移或清空数据。

网易云官方短信网页登录已经成功，授权保存在 App 原有安全仓库中。当前账号可读到 8 份歌单，本轮只选择两份小歌单（4 首和 1 首）导入，总计 5 首，失败和跳过均为 0；没有导入剩余 6 份，也没有修改云端歌单。

## 本轮改动

- 网易云网页登录不再记录页面 console 内容、原始导航 URL 或 HTTP 错误描述，避免认证页面把输入和请求信息带入应用日志。
- 导航栏 inset 改为缩小根布局的实测视口，修复 WebView 底部固定同意按钮被自身 padding 裁切的问题。该修复已编译；保留现有账号，没有退出重走新账号条款页。
- 旧 UUID 重建测试更新为当前 QQ/酷我正常音频能力，未知来源仍拒绝；官方外链测试允许音频来源的精确官方页面并继续拒绝跳转参数。
- 新增需显式启用的真实设备检查，不在普通测试中发起账号或外网请求。导入检查通过统一歌单 UUID 查到旧库 ID，核对线上歌曲顺序、歌曲 UUID、任务复用、重复导入及外键一致性。

## 实际验证

Huawei Mate60（BRA-AL00 / API 31），使用保留数据的 APK 覆盖安装。两份已导歌单的 5 首原始顺序与 UUID 反查均通过；再次提交相同任务复用 job ID，歌曲数量和顺序不变，没有新增重复项。Room 为 v23，`foreign_key_check` 为 0 行。

从已导歌曲中检查了 1 个候选，网易云正常接口按精确歌曲 ID 返回标准音质完整地址，解析器确认不是试听；随后经生产 PlayerManager 实际解码播放。该检查直接使用刚核实的原生地址，排除了备用源混入，不是绕过会员限制。取址 2920ms，播放请求到观察到进度耗时 5895ms，观察到位置 2157ms。

直接相关 JVM 检查 6 个通过。设备检查共 5 个，4 个通过、1 个 YouTube 失败，失败原始记录保留。最新 Debug APK 和 AndroidTest APK 构建成功并覆盖安装，模块边界检查通过。前一提交的远端 CI 失败来自旧 UUID 能力断言，本轮已修正；新 CI 以实际 Actions 状态为准。
