# Phase 2AT：手机网络恢复与酷我会话恢复

2026-10-28，优先处理用户反馈的点击后无法播放。

手机实际复现：播放停在0秒并提示无法获取地址；系统Edge打开酷我官网也显示`DNS_PROBE_FINISHED_NO_INTERNET`。重连原已保存Wi-Fi一次后仍失败，用户随后重新连接网络。此后App进程内匿名探测酷我HTTP200/734ms、网易云HTTP200/612ms。独立IP控制请求在TCP阶段3023ms超时，不能据此推断音乐平台不通。未修改DNS、代理、VPN、流量节省设置或任何凭据。

换网后真实生产播放器验证：酷我正常网页免费样本解码并观察2129ms进度；已有网易云导入歌曲检查3个候选后取得无试听标记的完整地址，771ms解析、2674ms观察到2159ms播放进度。不是每首歌曲都有当前账号的完整权限：刚才被点击的歌曲在换网后明确返回资源受限，不宣称全部免费可播。

生产代码补强：酷我API的HTTP401/403最多触发一次正常匿名会话刷新，重新取得详情并复核免费/在线/播放权限，再请求正常音频。根页面拒绝、429/500、网络异常、费用或权限JSON拒绝不触发该重试；保留调用者的共享截止时间。第二次HTTP拒绝直接传播，禁止无限刷新。

OkHttp回调只返回待接收Cookie和解析结果，只有持有互斥锁且仍处于活动状态的协程才能提交Cookie。已取消请求的迟到回调不能污染前台播放会话。
