# Phase 2BT — 拒绝试听回退，保留同录音完整来源的自动解析

日期：2026-10-30（Asia/Shanghai）。对应用户“哭泣少女乐队的所有歌只有试听”反馈。

## 改动

- 网易云返回试听时，跳过后续高档位，只保留标准档完整地址机会，再执行现有本地、已记忆来源和在线备用解析；不再把试听作为最终播放结果。
- 主播放与 UUID 入口统一拒绝明确标记的试听，移除备用列表中的试听。旧预取和完整缓存中的试听标记也会触发重新解析；保留原缓存文件和用户数据。
- 新安装/从未设置过的用户默认开启自动换源，用户显式保存的关闭值仍保留。沿用原歌手、标题、版本、时长和账号/决定复核，不以翻唱填补缺失的原唱。
- 原生来源仅试听后若成功切换，也记录短期主源失败提示。现有总体预算不延长。
- 没有找到符合条件的完整录音时显示简短提示；未返回伪造地址或未经授权的播放能力。

## 已执行

- 5 项直接相关 JVM 用例通过：3 项完整录音/备用/遗留音频标记，2 项设置默认值/显式关闭保留。
- 模块边界通过，累计 Debug 构建 4m57s。APK、版本、哈希见 [build.json](evidence/2026-10-30/phase2bt/build.json)。保留数据覆盖安装成功并核对版本。
- Mate60 在 `雑踏、僕らの街` / `トゲナシトゲアリ` 上显式点击播放，显示未找到原唱完整版；自己的媒体会话暂停、位置 0。验证了拒绝试听，尚未验证该曲的备用来源成功。
- 来源菜单显示 30 个候选；这是元数据发现数量，不能视为 30 个可播放地址。
- 一项 opt-in 设备诊断复用生产来源发现/单源检查，实际自动换源开关为 true。`雑踏、僕らの街` 发现 1369ms，酷我仅 2 个翻奏/片段，B站返回项未通过版本/标题等门槛；2 条其他网易云同名原唱记录检查为 UNAVAILABLE。`誰にもなれない私だから` 发现 1410ms，返回候选也未获得完整地址。该诊断耗时不是首声/自动切源时延。
- `空の箱` 补充查询选中 100120ms 的 live/edit 版本，不计作录音室版验证。初次诊断入口非 void 导致 runner 初始化失败，已修正并用 38s 增量构建重跑；不把初始化失败当音源失败。原始结构化结果见 [device-discovery.json](evidence/2026-10-30/phase2bt/device-discovery.json)。

## 限制

明确标记的试听拦截不等于完整音频文件鉴定。平台返回的权限、账号、版本证据与实际解码必须分别确认；本阶段不能宣称哭泣少女乐队全部歌曲已可播放。本机 runtime JVM 固定要求 JDK21，仍未执行该模块本地测试，未下载新工具链。

当前网易云候选封装把非登录失败统一折为 UNAVAILABLE，后续应保留“仅试听/无权限/超时”的具体原因，避免来源选择页掩盖实际失败。

## APK 普通逻辑复核

复核原已提取的 JavaScript ZIP，未执行样本或移植解锁逻辑。`select.js` 的前五项/时长近似后退首项，以及 `find.js` 删除翻唱标签的做法会引入错配，没有采用。只参考有界并发、先元数据后播放解析的职责分离。样本静态 `Promise.all`/`Promise.any` 不代表本机速度证据，也未证明存在统一的全部完整版接口。包许可证 LGPL-3.0-only，当前实现独立编写。归档、Evidence 与未覆盖范围沿用 [APK 审计](APK_SOURCE_AUDIT.md)。
