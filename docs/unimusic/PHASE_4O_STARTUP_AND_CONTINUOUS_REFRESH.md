# Phase 4O：启动账号初始化与前台持续高刷

2026-10-30。接续4N，并按用户最新澄清：所有前台音乐界面都需要高刷新率，不能只在切换时提高。

## 变化

- 真实启动采样发现AppContainer同步打开网易云/YouTube加密存储。网易云观察器的仓库读取移入IO协程，并先解析客户端lazy再取得cookie锁，避免首次加载时锁顺序反转。
- YouTube账号观察器在首屏就绪后从IO启动；首页不再为了停用的YouTube来源提前读取账号。来源启用时也在IO准备账号，首个流值按指纹去重，避免初始化/订阅之间账号变动被drop遗漏。保留已登录数据及原加密方式。
- 根据最新指令移除播放页3秒静置降到60Hz的策略、触摸计时与定时回调。高刷开启时，所有MainActivity内页面持续请求同分辨率最高刷新率，同时设置对应modeId；Android15+的视图帧率投票也持续保持。
- Activity进入后台或显式关闭高刷时释放请求；返回前台/窗口重新取得焦点时重新应用。没有改动系统全局设置，也不靠无意义循环强制重绘静止画面。
