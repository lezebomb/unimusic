# Phase 3B：本机播放反馈与推荐规则

2026-10-28（Asia/Shanghai）。

## 已实现

- 生产PlaybackStatsOwner接入独立反馈计时器，沿用已确认推进的引擎播放状态，暂停/缓冲不累计。手动拖动后本周期不作为听完或重复证据。
- SKIP仅来自本机用户确认的下一首/上一首、实际目标身份改变、有效播放至少2秒且低于30秒/曲长四分之一；自动完成、播放失败跳转、REMOTE_SYNC/LOCAL_SAFETY或被拒绝的队列/音量操作不进入这一路。未知时长不推断。
- COMPLETE要求自然结束、至少1秒且有效播放时间达到已知时长80%；REPEAT要求前次同曲满足完成条件且新周期实际推进至少2秒。事件不等于用户喜欢/不喜欢，不从历史缺记录推断负面偏好。
- 精确本机身份摘要、UUID事件ID、类型/时间/时长保存到私有 `playback-feedback-v1.json`；最多1000事件/512KiB、保留30天，排序仅使用14天内衰减证据。无歌名、路径、URL、账号凭据或新网络上传；不是独立UUID同步dataset。
- 有界64项后台队列，幂等事件ID和原子替换。首次事件才初始化运行时存储，维持原安全模式的仓库优先级；失败降级不阻塞权威播放统计。它是尽力记录，未承诺强杀/写盘故障下末次事件无损。
- 推荐规则版本升为3：精确身份近期多次跳过轻度降权，完成/重复给有限正向权重，仍保留多样性和现有理由。反馈修订触发日内重选，普通统计变化仍按原日快照规则处理。
- 清空统计推进私有反馈清除栅栏，单曲移除只移除对应摘要；显式30天隐藏偏好独立保留。Room仍v23，无新迁移，旧歌词/队列/账号存储不改。
