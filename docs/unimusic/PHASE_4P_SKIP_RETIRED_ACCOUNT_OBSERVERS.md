# Phase 4P — 常用入口不再初始化停用平台账号

2026-10-30（Asia/Shanghai）。接续用户要求优化加载/切换动画后台争用。

源码发现“我的”仍在 ViewModel 构造时获取 YouTube 加密仓库，搜索启动仍订阅 QQ 账号，来源菜单的初始快照和五路 combine 也会打开两者。它们都是当前产品已停用的在线源，无需参与普通页面初始化或使在用音源请求失效。

- 我的仅在来源注册表启用 YouTube 时启动其账号观察，仓库首次获取放 IO；网易云/B站刷新与本地歌单保留。
- 搜索跳过停用 QQ 的账号观察；未来若注册表重新启用，首次仓库获取也在 IO。
- 来源菜单用中性的内存值代替停用账号及开关流，跳过停用 QQ 的代次访问；启用来源的会话复核/决定/权限检查不变。

不修改已保存的账号、设置、歌单、历史或本地文件，不重新启用停用源，没有添加产品说明文案。

实际：app 编译与 2 项既有关键 JVM（账号变更/普通 Cookie 轮换、网易云刷新/退出）1m50s 通过，0 失败。未新增测试、单独打包或重复装机，等待下一批音源匹配改动累计安装。此处只确认移除明确的初始化工作，没有新启动/帧率对照，不宣称稳定 120fps。证据：[results.json](evidence/2026-10-30/phase4p/results.json)。
