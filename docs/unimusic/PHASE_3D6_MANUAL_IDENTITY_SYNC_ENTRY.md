# Phase 3D.6：显式标识同步入口

日期：2026-10-28。在设置的WebDAV卡片增加“同步歌曲标识”，仅点击时才从已有加密配置读取凭据并运行独立同步。不默认启用，不改旧同步调度或旧last-sync记录，也没有真实读取用户配置/上传验证。

入口说明只交换公开平台歌曲ID和元数据，歌单仍用原同步。界面只持有计数、pending和错误资源，不保存凭据、URL或完整dataset。显示本地/不支持来源排除数量、删除/冲突与尚未发送变化；当前没有冲突选择界面，不能将计数当成冲突已处理。

配置guard在请求前后检查捕获的配置代次。设置页离开或打开配置弹层时取消该页面请求；配置切换/清除后阻止后续请求及旧会话成功确认。已经发出的PUT无法撤回，测试和说明不将它说成能够回滚网络操作。错误UI使用固定文案，不回显异常正文/服务器私有信息。
